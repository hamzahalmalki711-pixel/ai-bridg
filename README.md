# AI Bridge — ChatGPT × Claude

موقع عربي للجوال مبني بـ Next.js. يرسل المهمة إلى OpenAI ثم مراجعة إلى Claude ثم تحسين إلى OpenAI، حتى 3 جولات.

## التشغيل محليًا

1. ثبت Node.js 20 أو أحدث.
2. نفذ `npm install`.
3. انسخ `.env.example` إلى `.env.local`.
4. أدخل مفتاحي API وكلمة مرور قوية في `.env.local` (لا ترفع هذا الملف إلى GitHub).
5. نفذ `npm run dev` وافتح `http://localhost:3000`.

## نشر آمن على Vercel

1. ارفع المشروع إلى **مستودع GitHub خاص** بدون ملف `.env.local`.
2. في Vercel: Add New Project → Import Git Repository → Deploy.
3. ضمن Project Settings → Environment Variables أضف `OPENAI_API_KEY` و`ANTHROPIC_API_KEY` و`BRIDGE_ACCESS_PASSWORD`، واختياريًا `OPENAI_MODEL` و`ANTHROPIC_MODEL`.
4. أعد النشر بعد إضافة المتغيرات.
5. تحقق من `/api/health` وأن `configured` تساوي `true`، ثم نفذ مهمة تجريبية قصيرة.
6. فعّل حماية الاستضافة/المصادقة المسبقة قبل نشر رابط عام. كلمة مرور التطبيق وحدها ليست نظام مستخدمين متكاملًا.

## الحماية والقيود

- لا تضع مفاتيح API في المتصفح أو في المحادثات أو في المستودع.
- كلمة مرور الموقع تُرسل إلى الخادم للتحقق في كل طلب ولا تُخزن محليًا؛ يجب استخدام HTTPS.
- السجل يحفظ آخر 20 نتيجة في **متصفح الجهاز فقط**، وليس قاعدة بيانات مشفرة أو مزامنة سحابية. لا تستخدم مهام حساسة.
- هذه نسخة MVP. للإنتاج أضف تسجيل دخول حقيقي، rate limiting، ميزانية إنفاق، سجلات مراقبة، تخزينًا آمنًا، وسياسة احتفاظ بالبيانات.
- قد لا تناسب مدة تنفيذ الخادم الطويلة خطة الاستضافة المجانية عند اختيار 3 جولات؛ ابدأ بجولة واحدة.
- تأكد من أسماء النماذج المتاحة في حسابي OpenAI وAnthropic. القيم الافتراضية في `.env.example` قابلة للتغيير.
- استدعاءات API تستهلك رصيدًا منفصلًا لدى المزودين.
